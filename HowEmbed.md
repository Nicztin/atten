This project demonstrates how to embed a Beatport track into an HTML page and add a link to your YouTube channel, allowing visitors to listen to the track and easily navigate to your channel.

Features

Embed Beatport Track: Allows users to listen to a specific Beatport track directly from your website.

YouTube Channel Link: Adds a clickable button to navigate to your YouTube channel, helping increase visibility and engagement.


Technologies Used

HTML: To structure the webpage.

CSS (optional, for styling): Used in the example to style the YouTube button.

iframe: To embed the Beatport track into your website.

YouTube Link: Directs visitors to your YouTube channel.


Setup Instructions

Prerequisites

VS Code: You need to have Visual Studio Code installed on your machine.

Live Server Extension (optional): For live previewing of your HTML in the browser.


Steps

1. Create a New HTML File:

Open VS Code.

Create a new file and save it as index.html.



2. Paste the Code: Copy and paste the following code into your index.html file:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Embed Beatport Track & YouTube Channel</title>
</head>
<body>
    <h2>Listen to Beatport Track</h2>
    <iframe src="https://embed.beatport.com/?id=12382829&type=track" width="100%" height="162" frameborder="0" scrolling="no" style="max-width:600px;"></iframe>

    <h2>Visit My YouTube Channel</h2>
    <a href="https://youtube.com/@nicztining?si=0TxCtv6o3Eo7Imo8" target="_blank">
        <button style="padding: 10px; font-size: 16px; cursor: pointer;">Go to My YouTube Channel</button>
    </a>

    <!-- Additional message -->
    <p>➡ ចុចប៊ូតុង នឹងនាំអ្នកទៅ YouTube Channel Nicztin!</p>
    <p>➡ Connect link to my channel</p>
</body>
</html>

Note: Replace the id in the Beatport iframe and the YouTube link with your actual IDs/URLs.


3. Open the File in the Browser: You have two options to view the HTML file:

Option 1: Right-click the index.html file in VS Code and select "Open with Live Server" (if you have the Live Server extension installed).

Option 2: Open the file directly in a web browser by navigating to the file's location and double-clicking it.



4. Test the Functionality:

You should see the Beatport track embedded and an interactive button linking to your YouTube channel.

When clicking the button, it will open your YouTube channel in a new tab.




Benefits of This Approach

User Engagement: Directly embeds audio content (Beatport track) and allows users to navigate easily to your YouTube channel for further interaction.

Visibility: By embedding both your music and YouTube content, you can increase your online visibility and attract more visitors to your platform.

Cross-Promotion: This integration helps in promoting your Beatport tracks and YouTube videos simultaneously, increasing the chances of more engagement from your audience.
